# Proposal: мини-трекер учебных задач на неделю

## Why
Нужен простой автономный инструмент. Он ведёт список учебных задач на неделю и показывает, какая доля запланированных часов уже выполнена. Инструмент работает без сети, CDN, внешних библиотек и API-ключей.

## What Changes
- Новая возможность `tracker`: список задач с полями `id`, `title`, `hours`, `done`.
- Операции: добавить задачу, удалить задачу, переключить `done`. Каждая операция реально меняет данные.
- Валидация формы: название после trim не пустое. Часы — число от 0,5 до 24 с шагом 0,5. Пустое значение не считается нулём. Ошибка показывается рядом с полем, введённые данные остаются в форме.
- Итоги: сумма часов всех задач, сумма часов выполненных задач и прогресс в процентах. Без NaN и Infinity.
- Фильтр «все» / «активные» меняет только видимый список. Итоги считаются по всем задачам.
- Стартовый пример: «Чтение» 2 ч (done), «Практика» 4 ч, «Повторение» 2 ч.
- Интерфейс читаем на ширине 390 px без горизонтального скролла. Все поля и кнопки подписаны.
- Необязательно: сохранение в localStorage. Если хранилище недоступно, показывается понятное сообщение, и работа продолжается в памяти.

## Варианты поставки
- **A**: один файл `tracker-v2.html`, CSS и JavaScript внутри.
- **B**: `index.html`, `styles.css`, `app.mjs` (интерфейс), `domain.mjs` (данные и расчёты), `tests/acceptance.test.mjs` (приёмочные тесты домена).

## Scope / Non-goals
- В рамках задачи: только перечисленное выше.
- Вне рамок: редактирование названия и часов существующей задачи, сроки и даты, дни недели, категории, сортировка, фильтр «выполненные», синхронизация, учётные записи, экспорт и импорт, сборщики и npm-зависимости.

## Impact
- Новая спецификация: `specs/tracker/spec.md`.
- Существующий код не затрагивается: проект создаётся с нуля.
- Спецификация и реализация выполняются разными запросами. На этом этапе код не пишется.
