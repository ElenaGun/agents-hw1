# ДЗ1 · Создание ИИ-агентов с нуля

Вариант A: сравнение прямого запроса и разработки по спецификации (формат OpenSpec, без CLI). Модель — Claude Opus 5.5 в двух отдельных чатах.

Скачать tracker-v1.html и tracker-v2.html, открыть браузером; отчёт в report.txt.

- tracker-v1.html — короткий прямой запрос (после одного исправления)
- tracker-v2.html — по спецификации
- proposal.md, spec.md, design.md, tasks.md — спецификация в формате OpenSpec
- prompts.txt — все промпты и уточнения
- report.txt — таблица проверок T1–T5, дефекты, вывод
- screenshots-v1/, screenshots-v2/ — подтверждения проверок
